# Express.js - Apresentação por Victória Tavares Carvalhal

## O que é Node.js
- Node.js é um enviroment que permite o desenvolvimento do backend com a linguagem javascript.
- Além disso ele é responsavel pelo desenvolvimento do Node Package Managment (NPM), programa bastante
usado na industria que possibilita baixar bibliotecas e frameworks de terceiros para projetos.

## Diferença entre Enviromment e Framework
- Um Framework é um grupo de bibliotecas que juntos modificam a maneira como você programa em certa
linguagem. Trazendo atalhos para problemas que levariam mais tempo para serem codados e resolvidos
- Já um enviroment é um ambiente onde você cria seus programas. Esse enviroment define qual tipo de linguagem você pode usar e o que você pode ou não fazer nele. 
- A linguagem é aquilo que você usa para mandar o computador fazer coisas para você
- Bibliotecas são grupos de codigos já programados por outra pessoa que ajudam a resolver problemas especificos
- Frameworks são um grupo de bibliotecas que resolvem vários tipos de problemas e facilitam muito mais como programar 
- Enviroment é o local onde todas essas coisas são feitas e sem ele não é possível mandar o computador fazer nada. Ele tem seu grupo de regras e restrições. 
- Node é um enviroment de service-side e permite programar o backend usando java script. Express é um 
framework criado especialmente para Node para facilitar o desenvolvimento de programas nesse enviroment. 

## Breve histórico do Node.js e Express.js 
- Node.js foi lançado em 2009 por Ryan Dahl, procurando fugir do paradigma de programação em sequencia 
que era vista como regra pelo enviromnet mais popular da epoca o APache HHTP server. 
- Em 2010 foi introduzido o Node Package Management (NPM), modificando completamente a maneria como se 
desenvolve web aplications para sempre. Possibilitando que programadores conseguissem baixar codigos de 
terceiros para suas maquinas de maneira facil e rapida.
- Em 2011, TJ Holowaychuk criou o express js com o objetivo de criar um framework minimalista que facilita-se o programador a desenvolver seus projetos mas ao mesmo tempo dando liberdade para ele
- Em 2015, foi criada a fundação Node fundation, com o objetivo de manter, disponibilizar suporte ao codigo e continuar desenvolvendo o framework de maneira limpa e segura.
