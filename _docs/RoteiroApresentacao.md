## O que é Node.js
- Node.js é um enviroment que permite o desenvolvimento do backend com javascript.
- Além disso ele é responsavel pelo desenvolvimento do Node Package Managment (NPM), programa bastante
usado na industria que possibilita baixar bibliotecas e frameworks de terceiros para projetos.
